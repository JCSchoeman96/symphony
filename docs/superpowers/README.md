# Superpowers methodology files

Files under `docs/superpowers/plans/**` and `docs/superpowers/specs/**` are developer methodology,
planning/design history, and procedural context.

They are not automatically current programme authority, runtime authority, trusted evidence,
acceptance decisions, or authorization. A plan or specification can guide work only when a separate
governing decision authorizes that work. It cannot grant its author lifecycle, merge, release, or
acceptance authority.

The repository's V4.1 Master Roadmap, current execution roadmap, accepted governance, and runtime
authority rules retain their precedence. Historical plans and specifications remain unchanged unless
a separately authorized task requires an update.
