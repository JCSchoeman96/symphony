# H-020 and H-030 Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a truthful routed-provider capability gate and durable single-node retry/review lineage on top of PR #4’s H-010 control-plane coverage.

**Architecture:** H-020 introduces `SymphonyElixir.Tracker.Capabilities` as the sole owner of provider capability vocabulary and routed requirements. `Tracker` resolves local adapter declarations without network access, and `Config.validate_settings/1` rejects routed configurations before dispatch while preserving WorkflowStore’s last-known-good behavior. H-030 adds a narrow DETS-backed `AttemptLedger` owned by each Orchestrator lifecycle; policy remains pure, safety state is synced before automatic follow-up, startup restores only counters/exhaustion after fresh tracker reads, and host rearm creates a new lineage while preserving history.

**Tech Stack:** Elixir 1.19 / OTP 28, Ecto embedded config schemas, OTP DETS, ExUnit, Mix tasks.
