# Repository-local skill authority

<!-- SYMPHONY_AUTHORITY_CLASS: PROCEDURAL_NON_AUTHORITY -->

A skill describes HOW an already-authorized responsibility may proceed. A skill never establishes
WHETHER that responsibility has authority.

Skills cannot create lifecycle or merge permission, grant credentials, enlarge capability
envelopes, establish programme acceptance, waive evidence requirements, or turn their output into
trusted evidence. They cannot override WorkControl, AuthorityDisposition, RuntimeAuthority,
SourceControl authority, or governing repository law.

Each skill uses an explicit authority-class marker. `PROCEDURAL_NON_AUTHORITY` is for ordinary
procedure. `LEGACY_COMPATIBILITY_PROCEDURE` identifies instructions limited to a legacy adapter
path. Advisory tools remain non-authoritative and state this in their own source.

Use these files only inside an already-authorized role and writable workspace. A skill does not
grant permission to change protected branches, mutate lifecycle state, merge, release, or accept
work.
